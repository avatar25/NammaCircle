# NammaCircle iOS

SwiftUI iOS app workspace for the NammaCircle MVP.

## Current Status

This folder contains source placeholders only. Create the Xcode project inside `/ios` when mobile implementation begins.

## MVP Screens

- Locality map and score detail
- Rent fairness check
- Kannada daily lesson and streak tracker
- Forum feed, post detail, and comments
- Quest list and points summary
- Mentor profiles and booking request flow

## Not Implemented Yet

- Production auth
- Payments
- Real AI
- Push notifications
- Advanced map clustering

## Suggested Next Step

Create a SwiftUI app target named `NammaCircle` and move the placeholder files into the app target.
