# Product Spec

## Product

NammaCircle helps newcomers survive and settle in Bengaluru with practical locality data, rent checks, Kannada lessons, community support, quests, and mentor access.

## MVP Modules

1. Locality map and scores
2. Rent fairness check
3. Kannada daily lessons and streaks
4. Forum posts and comments
5. Quests and points
6. Mentor profiles and bookings
7. Admin moderation dashboard

## Non-Goals

- Payments
- Real AI
- Production auth
- Legal or financial advice
- Fully automated moderation

## Primary User Stories

- As a newcomer, I can compare localities before choosing where to stay.
- As a renter, I can check whether a quoted rent seems fair for a locality and BHK type.
- As a non-Kannada speaker, I can learn one useful phrase daily and keep a streak.
- As a resident, I can ask Bangalore-specific questions in a forum.
- As a user, I can complete city quests and earn points.
- As a newcomer, I can browse mentors and request a booking.
- As an admin, I can review reported content and profile submissions.

## MVP Success Signals

- Users repeatedly check locality and rent information.
- Users complete Kannada lessons across multiple days.
- Forum posts receive helpful replies.
- Mentor booking requests are submitted without manual explanation.
